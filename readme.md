
# Reddit-Style Community Platform

## Overview

This project is a full-featured, Reddit-style community platform that allows users to create and join communities (subreddits), share posts, comment, and interact with content. Built with modern web technologies, it provides a responsive and intuitive user experience.

## Features

### User Features
- **Account Management**: Registration, login, and profile customization
- **Posts and Comments**: Create, edit, and delete posts and comments
- **Voting System**: Upvote or downvote posts and comments
- **Saved Content**: Save posts for later viewing
- **Community Subscriptions**: Subscribe to subreddits to customize your feed

### Community Features
- **Subreddit Creation**: Users can create their own communities
- **Moderation Tools**: Community management capabilities
- **Content Filtering**: Browse by popular, new, or other sorting methods
- **Community Types**: Different permission models for communities

### UI/UX Features
- **Responsive Design**: Optimized for desktop and mobile devices
- **Dark/Light Mode**: Customizable appearance
- **Accessible Components**: Built with accessibility in mind

## Technology Stack

### Frontend
- **React**: Component-based UI library
- **TypeScript**: Type-safe JavaScript
- **Tailwind CSS**: Utility-first CSS framework
- **Shadcn UI**: High-quality UI component library
- **Radix UI**: Accessible primitive components
- **React Query**: Data fetching and state management
- **Wouter**: Lightweight routing library

### Backend
- **Express.js**: Web application framework
- **TypeScript**: Type-safe server code
- **Drizzle ORM**: Database toolkit
- **PostgreSQL**: Relational database

### Other Technologies
- **Vite**: Fast, modern frontend build tool
- **ESBuild**: JavaScript bundler for backend code
- **Zod**: Schema validation
- **WebSockets**: Real-time updates for notifications

## Architecture

The application follows a modern full-stack architecture:

- **Client-Server Model**: Clear separation between frontend and backend
- **RESTful API**: Structured endpoints for data operations
- **TypeScript Throughout**: Shared types between frontend and backend
- **Component-Based UI**: Modular, reusable components
- **Responsive Design**: Mobile-first approach

## Use Cases

This platform is ideal for:

- **Community Building**: Creating spaces for people with shared interests
- **Content Sharing**: Enabling users to share and discover content
- **Discussions**: Facilitating conversations around various topics
- **Knowledge Sharing**: Allowing users to learn from each other

For detailed setup instructions, please refer to the [Developer Guide](./read.md).

## Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Access the application at: http://localhost:5000
